    chevron_right help How does resolution work?

    How to get the best resolution

    • The output is only as sharp as your smallest source image. Enlarging a small photo cannot invent detail — it just gets blurry.
    • When frames are different sizes, MagicFlow keeps each frame's own size. For a clean animation, set an explicit Width/Height so every frame matches.
    • Leave Width/Height empty to keep originals at full size (largest possible resolution, larger file).
    • The resize is shrink-only — it never upscales, so you never lose sharpness to fake enlargement.
    • For pixel-art or screenshots, prefer PNG/APNG (lossless). For photos, WebP gives the best size-to-quality ratio.
